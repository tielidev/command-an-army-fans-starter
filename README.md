# Command An Army Fans — Community Site Starter

An open-source starter structure inspired by the information architecture behind [Command An Army Fans](https://commandanarmyfans.org/), an independent fan-made resource for the Roblox game **Command An Army**.

The live website helps players find:

- unit profiles and a searchable Unit Wiki;
- an independently researched tier list;
- working codes and redemption notes;
- update coverage and change tracking;
- beginner, ranked, guild, and formation guides;
- an interactive army-building tool;
- multilingual navigation for an international player community.

Visit the live resource: **[Command An Army Fans](https://commandanarmyfans.org/)**

## What is included

This repository intentionally contains only a lightweight, content-free frontend framework. Production articles, game data, analytics configuration, advertising code, private assets, and deployment credentials are not included.

```text
.
├── app.js            # Small client-side entry point
├── index.html        # Semantic page shell
└── styles.css        # Minimal responsive styling
```

Create `content/` and `public/` directories when you are ready to add your own original guides, structured data, and properly licensed assets.

## Run locally

No build tools or dependencies are required.

1. Clone or download this repository.
2. Open `index.html` in a browser, or serve the folder with any static-file server.
3. Replace the placeholder sections with your own original, verified content.

## Suggested content model

A useful game-reference site can organize information into topic clusters:

- **Discover:** overview, screenshots, videos, and latest updates
- **Units:** roster, roles, skills, evolution paths, and counters
- **Strategy:** beginner guides, formations, ranked play, and guild systems
- **Wiki:** one evidence-backed page per unit or mechanic
- **Codes:** current codes, rewards, verification dates, and expired-code history

When adapting this starter, verify information in the live game, cite reliable sources, and avoid publishing copied or unverified material.
