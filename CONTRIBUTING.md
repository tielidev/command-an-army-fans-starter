# Contributing

Thank you for helping improve this generic game-reference starter.

## Before opening a contribution

- Keep changes focused on the reusable framework.
- Do not copy articles, images, unit data, or other content from the production website.
- Do not add credentials, analytics identifiers, advertising tags, or private assets.
- Use semantic HTML and keep the interface keyboard accessible.
- Only submit assets you created or have permission to redistribute.

For corrections concerning the live fan resource, use the contact options on [Command An Army Fans](https://commandanarmyfans.org/contact/).
